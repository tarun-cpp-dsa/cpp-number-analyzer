\# Resume Website



A simple and responsive \*\*personal resume website\*\* built using HTML and CSS.

This project presents my education, technical skills, projects, and professional information in a clean web-based format.



\## 🚀 Features



\* Personal profile section

\* Education details

\* Technical skills

\* Projects

\* Certifications

\* Contact information

\* Clean and simple layout

\* Responsive design



\## 🛠️ Technologies Used



\* HTML5

\* CSS3



\## 📂 Project Structure



```text

Resume/

│

├── resume.htm

└── README.md

```



\## ▶️ How to Run



1\. Download or clone this repository.

2\. Open the project folder.

3\. Double-click `resume.htm`.

4\. The resume will open in your web browser.



\## 🎯 Purpose



This project was created to build and showcase my personal resume using web technologies and to demonstrate my understanding of HTML and CSS.
